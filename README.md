# 极速 AI 抖音切片机 (Fast AI TikTok Slicer)

一个真正的“傻瓜式”全链路抖音智能切片工具。只需丢入一个抖音分享链接，剩下的全交由大模型与自动化脚本处理。在零额外操作的情况下，为你自动切割精华卡段，打乱、去重、混剪，最终合并输出一部属于你的高播放潜力短片！

## ✨ 核心功能亮点

- **一键智能全自动**：输入抖音链接，程序自动带你完成下载原片、提取音频、文案精准转录的全流程。中间产生的零碎素材将会在结束后“阅后即焚”，保证硬盘干干净净。
- **AI 智能寻爆点**：接入大本营级的 AI 大脑（基于阿里云百炼），帮你梳理字幕上下文，精确找到视频里的高潮与爆点，输出最具看点的短片段。
- **全系防查重去重处理**：对每一个切出的精选片段，都会在底层自动进行轻微的随机变调、变速、非破坏性裁剪、抽帧及色彩抖动处理，规避绝大多数平台的查重检测机制。
- **横竖屏无缝适配**：可选最终导出的排版方式。既支持手机原生 9:16 的刷屏竖长条，也支持经典 16:9 横屏展现格式。
- **极简可视化 UI**：提供清晰直观的可视化 Web 工作台面板，告别繁乱的命令行黑框！通过界面随时监视当前执行阶段的进度。内建资产管理页，轻松查看并直达产出的最终爆款长文件。

## 🚀 极速上手使用指南

### 1. 环境准备
本项目需要使用 Python 运行环境（推荐 Python >= 3.9）。

首先克隆本项目并安装基本依赖项：
```bash
pip install -r requirements.txt
```

**配置核心组件 FFmpeg**：
项目底层完全依赖开源音视频处理神器 [FFmpeg](https://ffmpeg.org/)。由于体积原因，本项目源码中未包含 FFMPEG 可执行文件。
- 你可以自行前往 FFmpeg 官网，下载包含 `ffmpeg.exe` 的 Windows build 版本。
- 将下载好的包解压后，**将其重命名为 `ffmpeg-master-latest-win64-gpl-shared` 并放置在当前项目根目录下**；
- （或者，你直接将 FFMPEG 的 `bin` 路径配置进系统全局环境变量 `PATH` 中也可以）。

### 2. 获取 API 密钥
本项目的大模型智能分段核心能力通过阿里云服务驱动（不需要自己写代码，只用填密钥就行！）：
- 访问 [阿里云百炼平台 (DashScope)](https://dashscope.console.aliyun.com/)，申请 API Key。
- 将生成的 Key **直接在我们的 Web UI 左侧栏的输入框中填入即可**，程序会自动将其保存并对环境生效！无需在此手动改动任何代码。

### 3. 一键起飞！
确保完成上方操作后，在项目根目录下打开命令行终端执行：
```bash
streamlit run app.py
```
终端将会提示一个本地的网页地址（通常为 `http://localhost:8501`），自动在浏览器中将其打开。

接下来：
1. 复制你想要二次创作切片的抖音视频链接（或分享口令）。
2. 在界面的中央文本框处无脑粘贴。
3. 点击 **✨ 立即开始处理 ✨**。
4. 全程免操作，在界面中看炫酷的过程自动跑完。
5. 成功后，你就能在界面自带的“最终成品输出空间”直接观赏成果，或者一键打开提取出来的专属视频文件夹！
